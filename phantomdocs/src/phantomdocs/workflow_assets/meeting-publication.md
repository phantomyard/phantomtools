# Meeting publication protocol — 1.0.0

Receive an existing audio/video recording, retaining its authenticated request
id, organization, requester and explicit domain/type context. Recording is an
artifact role, not a security category. Preserve the original recording.

Transcribe the recording, summarize the transcription, and create separate
published transcription and summary artifacts using the installation's declared
branding profile. Retain links to their source artifacts. Do not overwrite
source bytes or apply branding to signed third-party evidence. Only index final
publication references after validation; changing bytes afterwards invalidates
their recorded content hash. Minutes require a separately versioned protocol
extension; they are not synthesized by this initial protocol.

Missing tools, unavailable inputs, failed transformations or ambiguous context
block execution. Delivery invitations and expiring tokens are a separate layer;
category access is not an event-specific reader gate. No invitees, categories,
folders, document moves or credentials are inferred from recording titles.

This registry describes dependencies; it does not implement transformation
tools, upload results, authenticate remote senders or execute work.
