# Reference document protocol — 1.0.0

Accept one original document of any media type for metadata validation and
reference indexing. Classification is resolved from the declared domain/type;
artifact role `original` is not a security category. Preserve the original.
Do not transcribe, summarize, apply branding, move, or upload by default.
The executor must confirm the object can be read, then use the existing
PhantomDocs reference-indexing service. This registry only plans that call.

An authenticated intake adapter must bind the declared requester to the sender
before execution. A JSON requester field or CLI actor flag is not proof of
remote identity. Confirm the reference commit before reporting completion.
